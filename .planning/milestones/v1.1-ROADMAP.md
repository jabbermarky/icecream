# Milestone v1.1: Recipe Organization

**Status:** ✅ SHIPPED 2026-01-13
**Phases:** 10-11
**Total Plans:** 2

## Overview

Give users control over ingredient display order in recipes through drag-drop reordering with visual feedback and order persistence.

## Phases

### Phase 10: drag-drop-reorder

**Goal**: Implement drag-drop UI for table rows (visual reordering)
**Depends on**: v1.0 complete
**Plans**: 1 plan

Plans:
- [x] 10-01: Drag-drop UI implementation

**Details:**

Implemented drag-drop UI for reordering recipe ingredients:
- Added drag handle column (hamburger icon) as first column
- Made ingredient rows draggable (empty "add new" row excluded)
- Added RECIPE_COLS constant for column indices (avoid magic numbers)
- Drag event handlers: onDragStart, onDragOver, onDragEnter, onDragLeave, onDrop, onDragEnd
- Mousedown tracking to restrict drag to handle only
- Visual feedback: opacity during drag, border on drop target
- CSS styling for drag states and print media query

Bug fixes during UAT:
- Cursor on empty row (scoped to .draggable-row)
- Drag from anywhere (restricted to handle via mousedown)
- Safari text node issue (nodeType check)
- Footer row alignment (empty cells for drag column)
- Scale by ingredient broken (RECIPE_COLS constants)

### Phase 11: order-persistence

**Goal**: Persist order in recipe data structure and file format, sort button integration
**Depends on**: Phase 10
**Plans**: 1 plan

Plans:
- [x] 11-01: Sort indicator clearing, order persistence test

**Details:**

Completed milestone by integrating drag-drop with sort functionality:
- Modified onDrop() to clear sortBy state after drag-drop reorder
- DOM manipulation to remove sort indicator (▲/▼) from headers
- Added testOrderPersistence() test method
- Verified order persists through save/load cycle

## Milestone Summary

**Key Decisions:**

| Phase | Decision | Rationale |
|-------|----------|-----------|
| 10 | RECIPE_COLS constant for column indices | Avoid magic numbers; safer when columns change |
| 10 | Mousedown tracking for drag handle restriction | dragstart target is always the row, not clicked element |
| 11 | Clear sortBy on drag-drop reorder | Prevent misleading sort indicator after manual reorder |
| 11 | DOM-based test verification | window.Recipe reference becomes stale after setRecipe() calls |

**Issues Resolved:**

- Sort indicator persisting after manual reorder (Phase 11)
- Scale by ingredient broken after column shift (Phase 10)
- Footer row misalignment (Phase 10)

**Issues Deferred:**

- ISS-003: Scale button enabled without valid input (pre-existing bug)

**Technical Debt Incurred:**

- Touch/mobile drag not supported (out of scope for this milestone)
