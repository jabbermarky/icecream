### Decisions Made

- **The save KEY comes from the snapshot, not the live recipe.** P0.5's first
  version froze the payload at click time but kept reading `Recipe.Name` live
  across two awaits, and `edRecipeName`'s `oninput` writes to it per keystroke.
  Reproduced: record stored under `Mango V2.2` while its snapshot said
  `Mango V2.1`. Worse, the existence check asked about the old name while the
  write targeted the new one — IndexedDB `put` is an unconditional replace, so
  a *different* recipe could be clobbered with no overwrite prompt. Rule now
  logged as a learning: after taking a snapshot, derive EVERY downstream value
  from it, keys and messages included.
- **The dirty flag is only cleared when the live recipe still matches what was
  persisted.** P0.5 turned "inconsistent but captured" into "discarded and
  reported clean". There is no `beforeunload` guard anywhere, so
  ModifiedIndicator is the only unsaved-work signal.
- **`deepFreeze` skips values `Object.freeze` rejects.** It THROWS on typed
  arrays with elements — values `structuredClone` accepts and IndexedDB stores
  natively — so freezing would have refused to save *or* export storable data
  while blaming the user's recipe. Freezing must never be why data cannot be
  written. Map/Set/Date contents stay mutable; documented and test-pinned
  rather than fixed, since no recipe holds them.
- **The library-load handler has two phases with separate catches.** Fetch and
  validate, then apply. The single try used to span the mutation and told the
  user their stored record was damaged after their open recipe had already been
  replaced on a path that keeps no backup.
- **`containerProblem` validates `Ingredients` too.** The gate's whole job is
  to run before `importIngredients` touches the live library; an array there
  merged entries under numeric keys "0", "1".
- **Codex remains unusable for reviews in this container.** Failure correlates
  with run duration, not prompt size: sub-30s runs always succeed, 60s+
  file-reading reviews always hang with no output and no rollout file. A
  passing smoke test does not predict a review will complete. Three review
  rounds have now run Claude-side only.
