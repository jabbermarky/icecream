### Decisions Made

- **The review step is not optional.** P0.1 and P0.2 both shipped without one
  because the SessionStart briefing says what to build next but never said to
  review before calling it done. The review then found three criticals. Two are
  now in the briefing's conventions section.
- **Version guards fail CLOSED.** `containerSchemaVersion` first mapped every
  non-number to v1, so `SchemaVersion: "2"` bypassed the refusal and truncated.
  Now: absent = legacy v1, numeric-or-numeric-string = its value, anything else
  = Infinity (refuse). Three independent passes converged on this bug.
- **One refusal gate, two truthful messages.** `containerProblem()` is the
  single pre-mutation gate for every load path. Newer schema gets
  "update the app"; damaged records get "this record is damaged" — the null
  return used to be overloaded and every caller assumed newer-schema.
- **`Object.prototype.hasOwnProperty.call`, not the instance method** — JSON can
  create an own key named `hasOwnProperty` that shadows it and crashes
  hydration. Red team found this; it survives naive object-type checks.
- **Test harnesses inject the REAL module singletons.** The roundtrip harness
  had a private ingredient map while `importIngredients` mutated the module-level
  one, so "library untouched" assertions inspected the wrong object and could
  never fail.
- **XSS family filed, not fixed** (issue #13). Four pre-existing sinks; the
  Notes one is entangled with contenteditable formatting that has no test
  coverage, so fixing it blind risks silently stripping user formatting.
- **Codex is unusable for reviews in this container** — see Notes.

### Notes

- **Codex hangs on any long run.** Refined diagnosis (learning
  `codex-long-runs-fail-short-ones-work`): failures correlate with RUN DURATION,
  not prompt size and not the `-s` flag. Every sub-30s run today succeeded;
  every 60s+ file-reading review hung with zero output and no rollout file. One
  2-minute review did succeed at 14:40, so it is probabilistic per
  connection-second and degraded through the afternoon. **A passing smoke test
  does not predict a review will complete.** Do not burn turns retrying.
- **The six-pass review substitutes for codex.** Critical pass + testing,
  maintainability, security, performance specialists + Claude adversarial + red
  team. The red team pass earned its place: it found the `hasOwnProperty`
  shadow and the harness wiring flaw that five other passes missed.
- **The session-clear loop was tested end to end and works.** A fresh session
  picked up from the injected briefing, built P0.1, and this session resumed and
  built P0.2 on top — learning the state from the briefing, not from memory.
- `mirror-memory.sh` commits every turn but only pushes on compact/session-end,
  while `~/.claude/stop-hook-git-check.sh` wants zero unpushed commits per turn.
  They disagree by exactly one commit after any turn producing a learning. Fix
  if it nags: add `--push` to the `Stop` entry in `.claude/settings.json`.
- PR #11 is open/draft at `e0355f0`, `mergeable_state: clean`, zero comments,
