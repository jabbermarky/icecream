  is not meaningful** (maintainer) so the diff is keyed by name. The batch record

  the binder does and it produced 14 results-free batches. "No verdict" is a
  value (`nothing to note` vs `not evaluated`).

  full-text search, stop — tier 3 of the three-tier design is withdrawn) and no
  defect taxonomy. Six of the ten changes that actually altered the next batch
  came from prose, so the open field is where diagnoses live.
- **Merge method: squash.** 91 commits, 34 of them per-turn hook mirrors. Matches
  the #5 precedent; rationale survives in `.planning/` and the PR body.
- Issues grouped by root cause, not filed one-per-item — CLAUDE.md warns that an
  issue per step is how trackers rot.
