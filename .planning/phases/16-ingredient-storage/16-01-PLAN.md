<task type="auto">
  <name>Task 2: Modify app startup to load library ingredients</name>
  <files>js/features/ingredients.js, js/app.js</files>
  <action>
Modify ingredient loading to use library-first approach:

**In js/features/ingredients.js:**

1. Add new function `loadIngredientsFromStorage(storage)`:
   - Call `storage.loadIngredients()`
   - If result exists and has data, populate Ingredients object (same pattern as loadIngredients)
   - Return true if loaded from storage, false otherwise

2. Add new function `saveIngredientsToStorage(storage)`:
   - Call `storage.saveIngredients(Ingredients)`
   - Return boolean result

3. Export both new functions

**In js/app.js:**

1. Import the new functions from ingredients.js
2. Modify initialization sequence (after storage init, before DisplayIngredients):
   ```
   // Try library first
   const loadedFromLibrary = await loadIngredientsFromStorage(recipeStorage);
   if (!loadedFromLibrary) {
     // Fall back to default JSON
     await loadIngredients();
     // Bootstrap library with defaults
     await saveIngredientsToStorage(recipeStorage);
   }
   ```

This ensures:
- First run: Load JSON → Bootstrap library
- Subsequent runs: Load from library directly
- No user-visible change in behavior

Do NOT modify `loadIngredients()` - keep it as JSON loader. The new functions handle storage.
  </action>
