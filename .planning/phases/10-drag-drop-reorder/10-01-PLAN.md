<task type="auto">
  <name>Task 2: Add drag-drop event handlers for row reordering</name>
  <files>js/features/recipe-manager.js</files>
  <action>
Add module-level variable to track dragged row:
```javascript
let draggedRow = null;
```

Add these internal event handler functions (following existing pattern like onIngredientChanged):

1. onDragStart(event):
   - Set draggedRow = this (the row being dragged)
   - Add 'dragging' class to row for visual feedback
   - Set event.dataTransfer.effectAllowed = 'move'
   - Set event.dataTransfer.setData('text/plain', '') for Firefox compatibility

2. onDragOver(event):
   - event.preventDefault() to allow drop
   - event.dataTransfer.dropEffect = 'move'

3. onDragEnter(event):
   - If target row !== draggedRow, add 'drag-over' class

4. onDragLeave(event):
   - Remove 'drag-over' class from target

5. onDrop(event):
   - event.preventDefault()
   - Get target row (event.target.closest('tr'))
   - If target is valid and !== draggedRow:
     - Get the tbody
     - Determine if dropping above or below based on position
     - Use tbody.insertBefore() to reorder DOM
     - Reorder Recipe.Ingredients array to match new DOM order
     - Call SetRecipeModified() to mark recipe as changed
   - Remove 'drag-over' class

6. onDragEnd(event):
   - Remove 'dragging' class from draggedRow
   - draggedRow = null

Wire up handlers in CreateRecipeRow() for draggable rows:
- row.ondragstart = onDragStart
- row.ondragover = onDragOver
- row.ondragenter = onDragEnter
- row.ondragleave = onDragLeave
- row.ondrop = onDrop
- row.ondragend = onDragEnd

IMPORTANT: Only wire these handlers on rows that are draggable (not the empty "add new" row).

For reordering Recipe.Ingredients array: get all tbody rows, iterate to find the new order based on row.Name, rebuild the Ingredients array in that order.
  </action>
  <verify>Drag a row to a new position. The row should move in the DOM. The Modified indicator should appear. Check console for no errors.</verify>
  <done>Rows can be dragged and reordered. Recipe.Ingredients array updates to match visual order. Modified indicator shows.</done>
</task>
