<objective>
Improve merge dialog UX when loading recipes with ingredient conflicts.

Purpose: When loading an old recipe, ingredient values may differ from current library (library evolves over time). Provide clear context so users understand what changed and can make informed decisions.
Output: Context-aware merge dialog with recipe-specific messaging and clearer column labels.
</objective>

**Constraint from user discussion:**
- Library is ground-truth for ingredients
- Recipes are historical snapshots that may have outdated ingredient values
- User wants to see conflicts clearly with context about what changed
- Future versioning (locked vs evolving recipes) deferred - just improve messaging for now

**Existing behavior:**
- `importIngredients(dataObj, overrideExisting, mergeMessageMtml)` already supports custom messages
- Recipe loading from file (recipe-manager.js) and library (app.js) both call `importIngredients` without context
- Column labels are "Current" and "Imported" - not descriptive for recipe context
</context>
