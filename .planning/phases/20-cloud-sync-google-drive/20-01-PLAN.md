**Research findings (from ROADMAP.md):**
- Use Google Identity Services + gapi client library
- Use `drive.file` scope (only app's files, no Google verification required)
- Two libraries: GIS (accounts.google.com/gsi/client) for OAuth, gapi (apis.google.com/js/api.js) for Drive API
- Pattern: gapiLoaded() → initializeGapiClient() → gisLoaded() → ready

**Tech from Phase 12:**

<task type="checkpoint:human-action" gate="blocking">
  <action>Create Google Cloud OAuth credentials for Ice Ed</action>
  <instructions>
    Before implementation, create OAuth 2.0 credentials in Google Cloud Console:

    1. Go to https://console.cloud.google.com/
    2. Create new project "Ice Ed" (or select existing)
    3. Enable Google Drive API:
       - APIs & Services → Library → Search "Google Drive API" → Enable
    4. Create OAuth consent screen:
       - APIs & Services → OAuth consent screen
       - User Type: External
       - App name: Ice Ed
       - User support email: (your email)
       - Scopes: Add `https://www.googleapis.com/auth/drive.file`
       - Test users: Add your email (for development)
    5. Create credentials:
       - APIs & Services → Credentials → Create Credentials → OAuth client ID
       - Application type: Web application
       - Name: Ice Ed Web Client
       - Authorized JavaScript origins:
         - https://jabbermarky.github.io
         - http://localhost:5500 (for VSCode Live Server testing)
         - http://localhost:8000 (for Python server testing)
       - Authorized redirect URIs: (leave empty for implicit flow)
    6. Copy the Client ID (ends in .apps.googleusercontent.com)

    Note: No API key needed since we're using OAuth tokens for all requests.
  </instructions>
  <verification>You have a Client ID string ending in .apps.googleusercontent.com</verification>

<task type="auto">
  <name>Task 2: Create google-auth.js module</name>
  <files>js/storage/google-auth.js</files>
  <action>
Create Google authentication module with:

1. Constants:
   - CLIENT_ID (placeholder, will be set by user response from Task 1)
   - DISCOVERY_DOC = 'https://www.googleapis.com/discovery/v1/apis/drive/v3/rest'
   - SCOPES = 'https://www.googleapis.com/auth/drive.file'

2. State:
   - tokenClient (GIS token client)
   - gapiInited, gisInited (initialization flags)
   - authStateListeners (array for callbacks on auth state change)

3. Exported functions:
   - initGoogleAuth() - Main init function, returns Promise that resolves when both libraries ready
   - isSignedIn() - Returns boolean
   - getAccessToken() - Returns current token or null
   - signIn() - Trigger OAuth popup, returns Promise resolving on success
   - signOut() - Revoke token and clear state
   - onAuthStateChange(callback) - Subscribe to auth state changes
   - offAuthStateChange(callback) - Unsubscribe

4. Internal functions:
   - gapiLoaded() - Callback when gapi.js loads
   - initializeGapiClient() - Initialize gapi.client with discovery doc
   - gisLoaded() - Callback when gis client.js loads
   - notifyAuthStateListeners() - Call all registered callbacks

Pattern from Google quickstart but adapted for ES6 module export pattern.
Use dynamic script loading for gapi and GIS libraries (no changes to index.html yet).
  </action>
  <verify>Module exports all listed functions without syntax errors</verify>

</task>
