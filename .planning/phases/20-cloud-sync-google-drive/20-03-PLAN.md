Create UI module for cloud sync controls:

2. State:
   - syncButton, statusSpan (DOM refs)
   - uiCallbacks (Info, Warning, ErrorMsg, showModal)

3. Exported functions:

   initCloudSync({ btnCloudSync, syncStatus, Info, Warning, ErrorMsg, showModal }):
   - Store DOM refs and callbacks
   - Initialize Google Auth
   - Set up auth state listener to update UI
   - Wire up button click handler
   - Update initial UI state

   updateSyncUI():
   - If signed in: button shows "☁️ Synced" or "☁️ Sync Now", status shows ✓
   - If signed out: button shows "☁️ Sign In", status hidden

   setSyncStatus(status):
   - status: 'syncing' | 'synced' | 'error' | 'offline'
   - Update statusSpan class and content

4. Internal functions:

   handleSyncButtonClick():
   - If not signed in: call signIn(), show progress
   - If signed in: trigger manual sync (will be wired in Plan 04)
   - Handle errors gracefully

   showSignOutOption():
   - Show modal with "Sign out of Google Drive?" confirmation
   - On confirm: call signOut()

5. Button states:
   - Not signed in: "☁️ Sign In"
   - Signed in, idle: "☁️ Synced" (with small sign-out link or long-press menu)
   - Syncing: "☁️ Syncing..." (disabled)

Export initCloudSync for app.js integration.
