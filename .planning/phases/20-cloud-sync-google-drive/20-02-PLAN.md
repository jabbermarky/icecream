**Storage interface pattern (from Phase 12):**
- 5 methods: saveRecipe, loadRecipe, listRecipes, deleteRecipe, hasRecipe
- Returns Promises, graceful error handling (return null/false on failure)
- Ingredient methods: saveIngredients, loadIngredients, hasIngredients

**Drive API operations needed:**
- files.create() - Create new file with JSON content
- files.list() - List files with query filter (name, mimeType)
- files.get() with alt=media - Download file content
- files.update() - Update existing file content
- files.delete() - Delete file

**File naming convention:**
- Recipes: `ice-ed-recipe-{name}.json` (allows multiple recipes)
- Ingredients: `ice-ed-ingredients.json` (single file)
- All files use mimeType: 'application/json'
- Query filter: `name contains 'ice-ed-' and mimeType='application/json'`

  <action>
Create Google Drive storage implementation:

1. Import:
   - { createStorage } from './storage.js'
   - { isSignedIn, getAccessToken } from './google-auth.js'

2. Constants:
   - RECIPE_PREFIX = 'ice-ed-recipe-'
   - INGREDIENTS_FILE = 'ice-ed-ingredients.json'
   - MIME_TYPE = 'application/json'
   - APP_FOLDER = 'appDataFolder' (or null for root - decide based on visibility preference)

3. GoogleDriveStorage object with methods:

   async saveRecipe(recipe):
   - Check isSignedIn(), return false if not
   - Search for existing file: files.list({ q: `name='${RECIPE_PREFIX}${recipe.name}.json'` })
   - If exists: files.update() with new content
   - If not: files.create() with metadata and media body
   - Return true on success, false on error

   async loadRecipe(name):
   - Check isSignedIn(), return null if not
   - Search for file by name
   - If found: files.get({ fileId, alt: 'media' }) to get content
   - Parse JSON and return, or null on error

   async listRecipes():
   - Check isSignedIn(), return [] if not
   - files.list({ q: `name contains '${RECIPE_PREFIX}'` })
   - Parse file metadata to extract recipe names and modified dates
   - Return array of { name, updatedAt }

   async deleteRecipe(name):
   - Check isSignedIn(), return false if not
   - Find file ID by name
   - files.delete({ fileId })
   - Return true/false

   async hasRecipe(name):
   - Check isSignedIn(), return false if not
   - Search for file, return true if found

   async saveIngredients(ingredients):
   - Similar pattern to saveRecipe but with fixed filename

   async loadIngredients():
   - Search for INGREDIENTS_FILE, download and parse

   async hasIngredients():
   - Check if INGREDIENTS_FILE exists

4. Helper functions:
   - findFileByName(name) - Search and return file metadata
   - uploadFile(name, content) - Create new file
   - updateFile(fileId, content) - Update existing file
   - downloadFile(fileId) - Get file content as JSON

5. Export factory function:
   - initGoogleDriveStorage() - Returns validated storage instance via createStorage()

Use gapi.client.drive.files.* for all operations (handles CORS internally).
All operations should check isSignedIn() first and fail gracefully if not authenticated.
