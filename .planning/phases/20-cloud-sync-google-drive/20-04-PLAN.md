**Sync strategy:**
- On sign-in: Full bidirectional sync (merge local + cloud)
- On save: Push to both IndexedDB and Drive
- On load from library: Already in IndexedDB, no cloud action needed
- Conflict resolution: Use updatedAt timestamp, newer wins
- Ingredients: Single file, merge on conflict using existing diffIngredients pattern

- Phase 17: Fire-and-forget sync (don't block user workflow)

<task type="auto">
  <name>Task 1: Create sync-manager.js module</name>
  <files>js/storage/sync-manager.js</files>
  <action>
Create sync manager module:

1. Imports:
   - { isSignedIn, onAuthStateChange } from './google-auth.js'
   - { initGoogleDriveStorage } from './google-drive-storage.js'

2. State:
   - localStorage (IndexedDB instance)
   - cloudStorage (GoogleDrive instance, null if not signed in)
   - isSyncing (boolean flag)
   - lastSyncTime (ISO string)

3. Exported functions:

   initSyncManager(indexedDBStorage):
   - Store local storage reference
   - Subscribe to auth state changes
   - On sign-in: initialize cloud storage, trigger initial sync
   - On sign-out: clear cloud storage reference

   async syncAll():
   - If not signed in or already syncing, return
   - Set isSyncing = true
   - Sync recipes: merge local and cloud lists
   - Sync ingredients: compare and merge
   - Set isSyncing = false
   - Update lastSyncTime
   - Return { success: true, recipesSync, ingredientsSync }

   async syncRecipes():
   - Get local list: localStorage.listRecipes()
   - Get cloud list: cloudStorage.listRecipes()
   - For each local recipe not in cloud: push to cloud
   - For each cloud recipe not in local: pull to local
   - For conflicts (same name, different updatedAt): newer wins
   - Return sync stats

   async syncIngredients():
   - Get local: localStorage.loadIngredients()
   - Get cloud: cloudStorage.loadIngredients()
   - If both exist: merge (cloud wins for conflicts, or use updatedAt)
   - If only local: push to cloud
   - If only cloud: pull to local
   - Return sync result

   async pushRecipe(recipe):
   - Called after local save
   - If signed in: cloudStorage.saveRecipe(recipe)
   - Fire-and-forget pattern (don't await in caller)

   async pushIngredients(ingredients):
   - Called after local save
   - If signed in: cloudStorage.saveIngredients(ingredients)

   getSyncStatus():
   - Return { isSyncing, lastSyncTime, isCloudConnected: isSignedIn() }

4. Conflict resolution strategy:
   - Recipes: updatedAt timestamp comparison, newer overwrites
   - Ingredients: merge individual ingredients, cloud wins on per-ingredient conflicts
   - Log conflicts for user awareness (via console or status)
  </action>
